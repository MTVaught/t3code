# T3 Connect

This desktop fork does not use T3 Connect, Clerk authentication, or a hosted relay. Its builds
include no hosted service configuration, and the relay deployment workflow is kept under
`.github/disabled-workflows`.

Remote connections use servers that you control. See [Remote access](../user/remote-access.md).
For reference, [upstream's setup guide](https://github.com/pingdotgg/t3code/blob/v0.0.45/docs/operations/connect-setup.md)
describes the services used by upstream releases.
